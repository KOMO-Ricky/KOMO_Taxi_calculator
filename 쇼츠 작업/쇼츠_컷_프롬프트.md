# 마이택시플랜 홍보 쇼츠 — 컷별 프롬프트 (v2 · 50대 인물)

Google Flow(Veo)로 생성하는 대화형 쇼츠의 컷 프롬프트 모음.

- 비율: 세로 9:16
- 등장인물: **민수**(50대 중반, 회색 후드, 안경 없음) / **지훈**(50대 중반, 네이비 자켓, 얇은 원형 안경)
- 인물 일관성: Flow의 **캐릭터 자산**(MINSU / JIHOON)을 첨부해 생성
- v2 변경점: 인물 연령을 30대 초반 → **50대 중반**으로 변경 (타깃층 일치).
  인물 외 배경·카메라·연출·대사는 v1과 동일.

> ⚠️ **기존 캐릭터 자산을 그대로 쓰면 안 된다.** Flow의 캐릭터 자산은 프롬프트의
> 나이 묘사보다 우선하므로, 기존 MINSU/JIHOON(30대 얼굴)을 첨부하면 젊은 얼굴로
> 나온다. 50대 중반 남성 레퍼런스 이미지를 새로 만들어 캐릭터 자산으로 등록한 뒤
> 그것을 첨부할 것.

## 구성

```
컷1 (민수 고민)
  → 컷2 (지훈이 폰을 밀어줌, 카메라가 화면으로 다이빙)
  → [앱 화면녹화 삽입]
  → 컷3 (민수 확인 후 반응)
  → 컷4 (지훈 마무리)
```

## 대사

| 컷 | 화자 | 대사 |
|---|---|---|
| 1 | 민수 | 개인택시 좀 해보려는데 얼마 들지 감이 안 오네, 너 뭐 좀 아는 거 없어? |
| 2 | 지훈 | 이거 한번 봐봐. |
| 3 | 민수 | 이거 괜찮은데? 얼마나 드는지 한 눈에 보이네 |
| 4 | 지훈 | 고맙지? 커피는 네가 사라~. |
