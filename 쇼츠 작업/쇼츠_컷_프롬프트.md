# 마이택시플랜 홍보 쇼츠 — 컷별 프롬프트 (v2 · 50대 인물)

Google Flow(Veo)로 생성하는 대화형 쇼츠의 컷 프롬프트 모음.

- 비율: 세로 9:16
- 등장인물: **민수**(50대 중반, 회색 후드, 안경 없음) / **지훈**(50대 중반, 네이비 자켓, 얇은 원형 안경)
- 인물 일관성: Flow의 **캐릭터 자산**(MINSU / JIHOON)을 첨부해 생성
- v2 변경점: 인물 연령을 30대 초반 → **50대 중반**으로 변경 (타깃층 일치).
  인물 외 배경·카메라·연출·대사는 v1과 동일.

> ⚠️ **기존 캐릭터 자산을 그대로 쓰면 안 된다.** Flow의 캐릭터 자산은 프롬프트의
> 나이 묘사보다 우선하므로, 기존 MINSU/JIHOON(30대 얼굴)을 첨부하면 젊은 얼굴로
> 나온다. 50대 중반 남성 레퍼런스 이미지를 새로 만들어 캐릭터 자산으로 등록한 뒤
> 그것을 첨부할 것.

## 구성

```
컷1 (민수 고민)
  → 컷2 (지훈이 폰을 밀어줌, 카메라가 화면으로 다이빙)
  → [앱 화면녹화 삽입]
  → 컷3 (민수 확인 후 반응)
  → 컷4 (지훈 마무리)
```

## 컷2 안정화 워크플로 — 시작 프레임 고정 (권장)

컷2는 "폰이 눕혀져 있는 상태"를 Veo가 자주 어긋나게 그린다 (세워두거나,
마지막에 집어 들거나). **첫 프레임을 이미지로 먼저 확정**하면 시작 상태의
복불복이 사라진다.

1. Flow의 **이미지 생성**으로 아래 프롬프트를 돌려, 폰이 제대로 눕혀진
   장면 사진을 하나 고른다.
2. Flow의 **이미지→영상(프레임에서 만들기)** 에 그 사진을 시작 프레임으로
   넣고, 컷2 프롬프트(위 본문)를 그대로 입력해 생성한다.
3. 그래도 마지막에 폰을 집어 드는 컷이 나오면 버리고 재생성 — 다이빙으로
   끝나는 컷을 고른다.

## 변경 이력

- v2.13: 컷4 전경 민수를 컷1·3과 같은 '구석의 조각'으로 재구성 —
  어깨 가장자리 + 짧은 흰머리로 덮인 정수리 뒷부분만 보이게.
  귀·관자놀이가 화면에 없으므로 안경이 그려질 자리가 원천적으로 없음.
  (묘사로 안경을 막는 대신 구도로 차단하는 접근)
- v2.12: 컷4 전경 민수 뒷모습에 안경이 생기는 문제 — 부정문 'no glasses'가
  역효과. '관자놀이와 귀가 비어 있고 맨 피부와 흰머리만 보인다'는 긍정
  묘사로 교체. (현 v3 영상은 해당 부위 국소 블러로 후반 보정 완료)
- v2.11: 컷2 지훈 표정 — 대사 전후로 잔잔하고 여유로운 미소(gentle easy
  smile)를 띠도록 추가. 나머지는 v2.6 확정 문안 유지.
- v2.10: 컷4 ①'지훈만 말한다, 대사는 그의 것, 움직이는 입술은 그의 것뿐'
  명시 + 전경 민수 '내내 침묵하며 듣기만' 추가 (대사가 민수에게 붙는 문제)
  ②커피 마시는 동안에도 장난기 어린 반웃음이 또렷이 남도록 강화.
- v2.9: 컷4 ①대사를 명령형 '커피는 네가 사라~'에서 제안형

  'cheeky friendly suggestion, gently nudging'으로 완화
  ②커피 마실 때 정면 응시 대신 시선을 잔 쪽으로 부드럽게 내리고
  반웃음 유지 (무표정 응시가 위압적으로 보이는 문제 대응).
- v2.8: 컷4 웃음 수위 조정 — 함박웃음(wide grin) 대신 '입꼬리만 올라가는
  슬며시 장난스러운 반웃음(sly half-smile)'. 톤도 laughter → a hint of
  amusement로 낮춤. 나머지(singsong·문장 끝 올림·커피 한 모금)는 유지.
- v2.7: 컷4 보완 — ①대사를 '활짝 장난스러운 웃음을 지으며, 밝고 놀리는 듯한

  대사에 배어나게) ②대사 후 폰 터치 동작 제거, '짧게 웃고 머그잔 들어
  한 모금'으로 교체.
- v2.6: 컷2 ①오른손 한 손으로만 밀도록 명시(반대 손은 자기 쪽에 둠)
  ②멈춘 폰의 정렬을 '눕힌 채, 가지런히 놓인 카드처럼, 위쪽 모서리가
  친구를 향함'으로 지시 ③부감 종결에도 같은 비유로 프레임 정렬 부가.
